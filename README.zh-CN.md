# F1 2026 Speedometer HUD（中文说明）

**神似转播画面的 Assetto Corsa 速度表，把 2026 赛季转播里看不到的东西全部画出来：电池、MGU-K
功率、直线模式 SM、超车模式 OT 和 Boost。为 VRC Formula Alpha 2026（Pro 版）打造，跟随镜头车，回放里同样可用。English: [README.md](README.md)**

![demo](docs/demo.gif)

---

## 为什么做它

2026 规则把 F1 变成了能量比赛：350 kW 电机、4 MJ 可用电池、每圈最多 8.5 MJ 回收、用直线模式取代
DRS、再加上超车模式和 Boost 按钮。官方转播图形却删掉了电量条，也从不显示直线模式和超车模式的
状态，观众看不到车手整圈都在管理的那件事。

这是一个 Custom Shaders Patch（CSP）Lua 应用，画出熟悉的 MultiViewer 风格速度表盘，再加上 2026
赛车暴露出来的全部能量信息。它在游戏内实时读取车辆的私有遥测，把数据录进你的回放，并且可以跟随
镜头所在的任何一辆车，AI 也不例外。它不改动任何车辆或赛道文件，联赛校验不受影响。

## 你会看到什么

**表盘**按 MultiViewer 的几何和配色矢量重画：蓝色速度弧、绿色油门弧、红色刹车弧、车速、转速、
挡位。原来 DRS 徽章的位置换成三枚 2026 徽章：

| 徽章 | 暗色 | 颜色状态 |
| --- | --- | --- |
| `SM` 直线模式 | 不可用 | 白色 = 可用，按键预锁 · 蓝色 = 已预锁，进区自动开启 · 黄色 = 已在区内仍可用 · 绿色 = 翼面已处于直线模式位置 |
| `OT` 超车模式 | 不可用 | 白色描边 = 已获得资格，等待激活线 · 绿色 = 本圈激活 |
| `BOOST` | 关闭 | 按住或切换 Boost 时为品红色 |

**表盘两侧的竖条**（可关闭）：左边是可用电量，标百分比和 MJ；右边是本圈已回收能量对回收上限
的比例。

**能量面板**（可关闭，一个按键切换）：

- 电池：可用能量条、百分比和 `MJ / 4 MJ`。
- MGU-K：实时功率，部署为绿色、回收为红色，并用刻度标出当前功率上限。上限标签在功率削减区显示
  `上限 200 kW`，禁止部署时显示 `上限 0 kW`，全油门强制回收时显示 `强制回收 -350 kW`。
- 本圈能量：本圈部署 MJ、本圈回收 MJ 与回收上限（8.5 MJ，超车圈 9.0 MJ），数字加进度条。
- 策略：`STRAT n`、当前部署地图分段、PU 模式名。
- 状态标签：SM 状态、OT 状态、Boost、充电模式、PL / PLP（功率受限状态）、维修区限速。

一切都跟随**镜头聚焦的车**，回放里切到谁就看谁的能量账。一个可绑定的按键可以把 HUD 锁回自己的车。

## 一分钟看懂 2026 三大系统

- **直线模式 SM（X 模式）**：前后翼活动翼片同时打开减阻。每辆车在每个指定区、每一圈都能用，
  没有一秒差距的条件。VRC 的实现：进区前在 200 km/h 以上按下按钮（默认就是 DRS 键）预锁，区起点
  处全油门且 150 km/h 以上翼片打开，刹车或油门低于 90% 时关闭。
- **超车模式 OT**：电力工具，不是空气动力学。在检测线与前车差距一秒以内，下一圈 MGU-K 的 350 kW
  可以一直保持到 337 km/h 再递减（平时从 290 km/h 开始递减），并多 0.5 MJ 回收额度。练习和排位赛
  常开。
- **Boost**：手动覆盖部署地图，把 MGU-K 推到当前功率上限。它决定电用多快，OT 决定上限多高。
- **PL / PLP**：规则对功率变化的限制（全油门至少维持 200 kW 一秒、削减不超过 150 kW、变化速率
  受限）产生的"功率受限"和"待受限"状态。

## 运行要求

- 装有 Custom Shaders Patch 的 Assetto Corsa。VRC Formula Alpha 2026 本身要求 CSP
  0.3.0-preview542 或更新，应用不需要更高版本（在 build 4116 上开发和测试）。
- **VRC Formula Alpha 2026 的 Pro（CSP）版**（`vrc_formula_alpha_2026_csp`）。能量数据来自这辆车的
  遥测总线；换其他车时表盘照常工作，能量面板显示 `--`。
- 不需要 DLL、SimHub、Python 或任何额外文件，一个文件夹两个文件。

## 安装

**方式 A，发布压缩包。** 在 [最新发布](../../releases/latest) 下载
`f1-2026-speedometer-hud-v0.9.0.zip`，解压到 Assetto Corsa 根目录（有 `acs.exe` 的那个），得到
`assettocorsa\apps\lua\f1_2026_speedometer_hud\manifest.ini` 即可。把压缩包拖进 Content Manager 也行。

**方式 B，从源码。** 克隆仓库，用 PowerShell 运行 `tools\deploy.ps1`，需要时加
`-AcRoot "D:\path\to\assettocorsa"`。

进入游戏后打开 CSP 的应用侧边栏，启用 **F1 2026 Speedometer HUD**。HUD 窗口没有背景，鼠标悬停会
出现标题栏，拖到想放的位置即可。

## 使用

- 点 HUD 悬浮标题栏上的齿轮打开设置。
- **显示**：缩放、显示能量面板、显示两侧竖条、跟随镜头聚焦的车、锁定玩家车、表盘字体（默认
  Bahnschrift）、中文字体（默认 Microsoft YaHei UI）。
- **语言**：English 或简体中文，即时切换。SM、OT、BOOST、PL、PLP、STRAT、PU、MGU-K、KMH、RPM、
  GEAR 这些转播缩写在两种语言下都保持英文，和中文频道的 F1 转播一致。
- **按键绑定**：两个可绑定到键盘或方向盘的按键，"切换能量面板"和"锁定玩家车"。
- **回放**：把所有车的能量数据录进回放（默认开启）。
- **诊断**：面板下方的数据来源小字、诊断文件，以及一个"日志模式"复选框，勾选后显示原始数值。

## 回放

Assetto Corsa 自己的回放不保存电池和 ERS 数据，Lua 应用也读不到车辆脚本的私有回放流。所以应用在
你开车时自己录一条流：22 个车位，每车 11 字节，每两帧一次，回放文件大约每小时多 13 MB。应用运行
期间保存的回放，回放时每辆车都有完整能量面板，赛中回放同样可用。没有应用时录的回放只有表盘和
直线模式徽章（翼面开合是 AC 回放自带的），其余显示 `--`。装了应用的人都能看到你录的回放里的数据。

## 设置一览

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 缩放 | 1.00 | 0.5 到 2.5 |
| 显示能量面板 | 开 | 也可绑定按键 |
| 表盘两侧显示电量和回收竖条 | 开 | |
| 跟随镜头聚焦的车 | 开 | 没有聚焦车时回落到玩家车 |
| 锁定玩家车 | 关 | 也可绑定按键 |
| 字体 / 中文字体 | Bahnschrift / Microsoft YaHei UI | 任何已安装的 DirectWrite 字体 |
| 语言 | English | 可切换简体中文 |

## 数据来源与联赛安全

实时模式下，车速、转速、挡位、油门、刹车、电池状态和 STRAT 来自 CSP 的车辆状态；2026 专属通道
（MGU-K 功率和上限、本圈部署 / 回收和回收上限、部署分段、PU 模式、超车、Boost、充电模式、
PL / PLP、直线模式锁存与激活）来自 VRC 赛车的遥测总线，通过 CSP 共享存储在运行时读取。不从磁盘
读取、也不修改任何车辆或赛道文件，校验值不受影响。通道名和回放流布局见
[docs/DATA-CONTRACT.md](docs/DATA-CONTRACT.md)。

## 常见问题

- **长时间显示 "waiting for the CAN map"**：车辆在会话开始几秒后才发布遥测表（正赛启动后约 15
  秒）。如果一直不出现，确认用的是 Pro（CSP）版车辆，并检查 `content\cars\vrc_formula_alpha_2026_csp`
  里 `data.acd` 旁边**没有解包出来的 `data` 文件夹**。车辆的物理脚本在存在松散 data 文件夹时会拒绝
  运行，车点不着火，所有遥测消费者都会空白。删掉这个文件夹即可。
- **面板显示 `--`**：聚焦的车不是 FA26 Pro，或者你在看没有应用时录制的回放。
- **中文标签显示不正常**：在设置里换一个中文字体。
- **诊断**：`Documents\Assetto Corsa\logs\f1_2026_speedometer_hud_diag.log` 跨启动累积；CSP 日志里也
  有同样的行，标签 `[F1-2026-HUD]`。

## 限制与计划

- 序号 22 及以后的车不录进回放。
- 目前只支持 FA26。DRS 时代车辆的降级显示、区间距离条、单圈能量历史、上限来源标签在计划中。
