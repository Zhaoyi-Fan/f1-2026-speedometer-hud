# F1 2026 Speedometer HUD（中文说明）

[English](README.md)

一款用于 Assetto Corsa 的 F1 转播风格 HUD。根据当前镜头车辆，自动选择 FA26 Pro、普通 FA26
或常规 DRS 显示，保留 v0.9.1 的圆形仪表设计，并支持查看已录制的车辆状态。

**0.9.38** 版新增电池图标接头方向的设置：接头在左（与之前相同），或在右（整个图标左右镜像）。
**0.9.37** 版修掉了一个录制缺陷：0.9.2 以来录下的 Pro 回放，在直线模式开启的那些帧里完全没有能量数据。
**0.9.36** 版在按住 Boost 时把 `BOOST` 写进电池图标内部。**0.9.35** 版在 **0.9.3** 引入的表盘内
电池图标（取代原两侧竖条）基础上，让普通 FA26 也能看到
自己的部署；`BOOST` 字样两台车都有，Pro 的数据接口沿用 0.9.3，普通车的紧凑面板多了一个标签，
两条回放流的布局沿用 0.9.2。每一版各改了什么见[更新日志](CHANGELOG.md)，开头有一行一版的速览表，后面是详细条目。
已实测与待实测项见[兼容与验收记录](docs/COMPATIBILITY.md)。
油门弧显示的是 AC 的物理油门，自动挡升档的短暂断油和降档补油都会如实显示
（见[已知问题](docs/KNOWN-ISSUES.md)）。

![demo](docs/demo.gif)

*演示录制于 v0.9.1 表盘更新之前；新版表盘见下方示意图。*

应用通过 Custom Shaders Patch（CSP）运行，将 MultiViewer 风格的表盘与车辆能量遥测放在一起，
方便驾驶或看回放时观察电量消耗和回收情况。不修改车辆或赛道文件。AI、远程车辆可能只提供部分数据，
不会拿玩家当前按键替代被观看车辆的状态。

## 车型适配

| 车辆 | 仪表 | 能量和回放 |
| --- | --- | --- |
| FA26 Pro，精确 ID `vrc_formula_alpha_2026_csp` | SM／OT／BOOST | 完整 Pro 面板与原有 Pro 回放流 |
| 普通 FA26，精确 ID `vrc_formula_alpha_2026` | 简化 SM／OT／BOOST，OT 暗置（该车没有超车模式通道） | 电池百分比、LOW／MEDIUM／HIGH／NODEPLOY、手动 BOOST、减阻、部署请求和回收状态 |
| FA25 等常规车辆 | 单个居中 DRS，有效开启时绿色 | 不显示 Pro 能量面板；已确认原生回放缺失的精确 FA25 CSP 车型补录 DRS |
| 无 DRS 车辆 | 同一个 DRS 标识，始终暗置 | 无能量面板 |

**车辆决定布局，赛道和规则影响可用性，实际状态决定点亮。**FA25 上 2026 赛道仍显示 DRS；
Pro 暂时缺 CAN 数据也不会变成旧规布局。缺失状态保持暗灯或 `--`，内部与已知关闭／真实零值分开。

## 显示内容

**表盘：**显示车速、转速和挡位，蓝色弧线表示车速，绿色表示油门，红色表示刹车。
车速刻度为 0–360 km/h，每 60 一格；超过 360 时蓝弧保持填满，中央数字继续显示实际车速。
油门和刹车弧线上分别标有 `THROTTLE` 和 `BRAKE`。布局和配色参考 MultiViewer 风格，
由代码绘制。**FA26 Pro** 表盘内还有三个状态标识：

| 标识 | 暗色 | 颜色含义 |
| --- | --- | --- |
| `SM` 直线模式 | 不可用 | 白色 = 可用，按键预锁 · 蓝色 = 已预锁，进区自动开启 · 黄色 = 已在区内仍可用 · 绿色 = 翼面已处于直线模式位置 |
| `OT` 超车模式 | 不可用 | 白色描边 = 已获得资格，等待激活线 · 绿色 = 本圈激活 |
| 电池图标 | `--`，环暗置 | 按住或切换 Boost 时电池体为品红色并显示 `BOOST` · 环和接头：回收时红色、部署时绿色、Boost 部署时品红色，功率越大越亮 · 闪电同色，电池体为品红时闪电为白色 · 显示的电量不高于 10 % 时填充和数字转琥珀色 |

**电池图标：**在 `SM`／`OT` 下方那一格显示可用电量，百分比写在电池内。默认接头在左、填充靠右：
部署时剩余电量的边缘向右退，回收时向左长，与面板里 MGU-K 条的方向一致。在设置里把接头改到右边，
画出来的就是它的镜像，与常见电池图标的朝向相同：填充靠左、电量向左减少，闪电挨着接头，百分比在另一端；
文字不会被反过来，除了位置之外什么都不变。外圈显示当前帧的 MGU-K
能量流向，亮度、线宽和光晕在 Pro 上随功率变化、在普通 FA26 上随部署请求变化；除可选的 120 ms
亮度平滑（默认开启，状态和颜色永不平滑）外
没有任何自行运动的动画。电池体沿用原 `BOOST` 徽章的规则显示
Boost 按键，所以按着 Boost 冲进刹车区时会看到品红电池体加红色外圈；按住期间电池内的百分比会让位给
`BOOST` 字样——填充条仍在，电量依然能按长度读出，而当电量掉到个位数时，琥珀色的数字会回到字样旁边。
在设置里关闭电池图标即可换回 `BOOST` 徽章。

**Pro 能量面板：**可在设置中开关，也可以绑定键盘或方向盘按键切换。

- 电池：可用能量条、百分比和 `MJ / 4 MJ`。
- MGU-K：实时功率，部署为绿色、回收为红色，并用刻度标出当前功率上限。上限标签在功率削减区显示
  `上限 200 kW`，禁止部署时显示 `上限 0 kW`，全油门强制回收时显示 `强制回收 -350 kW`。
- 本圈能量：以 MJ 显示已部署和已回收能量，并用进度条表示回收额度的使用情况。回收上限读取自车辆，
  随赛道和会话类型变化；超车模式下增加 0.5 MJ。
- 策略：`STRAT n`、当前能量部署分段、PU 模式名称。
- 状态标签：SM 状态、OT 状态、Boost、充电模式、PL / PLP（功率受限状态）、维修区限速。

**普通 FA26** 使用更紧凑的面板，显示电池百分比、真实部署档名以及“正在部署”／“正在回收”两个标签。
它的电池图标在车辆的输出控制器请求能量时显示绿色外圈，亮度取自这个请求；车辆报告回收时显示固定亮度的
红色外圈；按下按键时电池体为品红色。这个请求是当前油门和车速下所选档位要求的比例，不是实测输出功率：
`NODEPLOY`、极低车速和接近极速时外圈不会变绿（此时若在回收仍会是红色），这是车辆的正常行为；
绿色和红色是两套各自声明的亮度标尺，
彼此之间以及与 Pro 的功率标尺都不能互相比较。
BOOST 表示原生手动覆盖命令，自动部署不会将它点亮，也不承诺电机实际输出功率。
SM 只表达关闭／可用／开启，不显示 Pro 的预锁或晚操作状态。OT 始终暗置，因为该车没有超车模式通道。
“正在回收”不同于 Pro 的 Charge／Anti 按键模式，也不保证每一帧电池净增加。
不套用 Pro 的 4 MJ 容量、kW、每圈回收额度、split 或 PU 模式。

HUD 默认跟随**镜头中的车辆**。看回放时切换车辆，就能查看对应车辆已录制的数据；也可以绑定按键，
让 HUD 始终显示自己的车。

## 2026新规

以下说明对应 VRC Formula Alpha 2026 Pro 中各系统的实现。

- **直线模式 SM（X 模式）**：打开前后翼活动翼片以减小阻力，所有车辆都能在指定区域使用，无需满足
  与前车的时间差条件。进区前，车速达到 200 km/h 时可按键预锁（默认使用 DRS 键）；到达区域起点，
  在全油门且车速超过 150 km/h 时开启。刹车或油门低于 90% 时关闭。
- **超车模式 OT**：调整 MGU-K 的功率上限。经过检测线时与前车相差不超过 1 秒，即可在下一圈使用：
  350 kW 功率可维持到 337 km/h，而通常从 290 km/h 起就开始递减；同时增加 0.5 MJ 回收额度。
  练习和排位赛中始终启用。
- **Boost**：手动覆盖能量部署策略，请求 MGU-K 按当前功率上限输出。实际输出仍受剩余电量和功率限制
  约束，包括超车模式对应的上限。
- **PL / PLP**：分别表示功率受限和等待进入受限状态，对应规则中对功率变化的约束，包括全油门时
  至少维持 200 kW 一秒、削减幅度不超过 150 kW，以及功率变化速率限制。

## 运行要求

- 装有 Custom Shaders Patch 的 Assetto Corsa。VRC Formula Alpha 2026 本身要求 CSP
  0.3.0-preview542 或更新版本。本应用在 build 4116 上开发和测试。
- 完整 Pro 能量数据需要 **VRC Formula Alpha 2026 Pro**。普通 FA26 和常规 DRS 走独立接口；
  不承诺支持其他厂商的自定义 2026 系统。
- 应用由两个 Lua 文件和一个 manifest 组成，无需另外安装 DLL、SimHub 或 Python。

## 安装

**使用发布包：**在 [v0.9.38 发布页面](https://github.com/Zhaoyi-Fan/f1-2026-speedometer-hud/releases/tag/v0.9.38)
下载 `f1-2026-speedometer-hud-v0.9.38.zip`，
解压到 Assetto Corsa 根目录（包含 `acs.exe` 的文件夹）。解压后应能找到
`assettocorsa\apps\lua\f1_2026_speedometer_hud\manifest.ini`。也可以将压缩包拖入 Content Manager 安装。

**更新旧版：**先退出当前游戏会话，再将新版压缩包覆盖安装到原位置，允许替换应用文件。
现有 HUD 设置会保留。重新进入比赛或回放后，可在设置窗口确认版本为 **0.9.38**。表盘不再有两侧竖条，
窗口对所有车型都是 340 个单位宽（加面板）；之前开着竖条时 Pro 宽 98、普通 FA26 宽 62 个单位，
能量面板因此更靠近表盘，位置不合适的话拖一次即可。

**从源码安装：**退出 AC 后，用 PowerShell 运行
`tools\deploy.ps1 -AcRoot "D:\path\to\assettocorsa" -BackupRoot "D:\HUD-backups"`。
备份位置必须在仓库和游戏目录之外。脚本仅备份、覆盖并校验三个受管应用文件，保留设置及无关文件。
回滚使用相同脚本与 `-AcRoot`，加
`-RestoreManifest "D:\HUD-backups\<deployment>\deployment.json"`。

进入游戏后打开 CSP 的应用侧边栏，启用 **F1 2026 Speedometer HUD**。HUD 窗口没有背景，鼠标悬停会
出现标题栏，拖到想放的位置即可。

## 使用方法

- 点击 HUD 悬浮标题栏上的齿轮打开设置。
- **显示**：缩放、显示能量面板、表盘内显示电池图标（关闭 = `BOOST` 徽章）、电池接头方向（左或右，
  鼠标悬停可看区别）、电池环亮度平滑、跟随镜头聚焦的车、锁定玩家车、表盘字体（默认 Bahnschrift）、
  中文字体（默认 Microsoft YaHei UI）。
- **语言**：可随时切换 English 或简体中文。SM、OT、BOOST、PL、PLP、STRAT、PU、MGU-K、KMH、RPM、
  GEAR 等缩写在两种语言下保持一致。
- **按键绑定**：可将“切换能量面板”和“锁定玩家车”绑定到键盘或方向盘按键。
- **回放**：记录车位 0–21 的已支持状态，默认开启。
- **诊断**：可在面板下方显示数据来源、查看诊断日志，或开启“日志模式”查看原始数值。

## 回放

原 Pro 流保持不变：22 个车位，每位 11 字节，每两帧记录一次。
新增独立原生状态流：22 个车位，每位 6 字节，每个回放帧记录，带车型／车位关联和逐字段有效位。
它记录普通 FA26 必要状态，以及精确 FA25 CSP 的 DRS；其他常规车辆不会一律补录。
回放实际增量取决于帧间隔和压缩，不给所有场景套用同一个体积估算。

0.9.35 把普通 FA26 的部署请求也写进了这条流，但没有改变它的体积和布局：请求放在原本只记录档位索引
那一字节的四个空闲位里。早期版本录制的回放照旧完整还原；0.9.35 录制的回放在早期版本里打开时，
普通 FA26 的档名会显示为不可用（那些版本只把这一字节当作单纯的索引），其余字段仍然正常还原。

只要回放中保存了这些数据，HUD 就能在已保存的回放和赛中回放里显示对应的能量信息。
将回放分享给其他装有本应用的用户，对方也能查看。

旧 Pro 回放保留原流读取，缺流时仍可用仅限 Pro 的原生 H／I 翼面后备信号。
0.9.2 到 0.9.36 录下的回放，在直线模式开启的那些帧里没有任何能量数据；0.9.37 起这些帧会正常录下，
但已有文件无法修补。
已测试的旧普通 FA26 回放没有还原电量、手动 BOOST 或切档历史，缺少有效记录时这些数据保持未知。
已测试的 FA25 旧回放也未还原原生 `drsActive`，所以 DRS 暗置，但不能理解为“已证实尾翼关闭”。
其他车型和字段的原生回放可靠性需分别验证；接口返回 false／0 不等于可靠历史。
升级或重新播放旧文件不会为它补上缺少的历史。

关闭录制会清空实时写入缓冲，播放时只读。每次读取重建当前车辆状态，暂停、倒拖、切车不沿用前一个
快照。分享回放无需附带其他文件；诊断日志和设置存储与回放无关。

## 数据来源

Pro 实时运行时，车速、转速、挡位、油门、刹车、电池状态和 STRAT 来自 CSP 的车辆状态。2026 相关通道
（MGU-K 功率和上限、本圈部署 / 回收和回收上限、部署分段、PU 模式、超车、Boost、充电模式、
PL / PLP、直线模式预锁与激活）来自 VRC 赛车的遥测总线，通过 CSP 共享存储在运行时读取。
应用不从磁盘读取或修改车辆、赛道文件，因此不会改变这些文件的校验值。通道名称和回放格式见
[docs/DATA-CONTRACT.md](docs/DATA-CONTRACT.md)。

## 常见问题

- **长时间显示 `waiting for the CAN map`**：车辆在会话开始几秒后才发布遥测表（正赛启动后约 15
  秒）。如果一直不出现，确认用的是 Pro（CSP）版车辆，并检查 `content\cars\vrc_formula_alpha_2026_csp`
  里 `data.acd` 旁边是否有**解包后的 `data` 文件夹**。存在这个文件夹时，车辆物理脚本会拒绝运行，
  导致车辆无法启动、HUD 收不到遥测数据。将该文件夹移出车辆目录后，重新进入会话。
- **某个值显示 `--`**：该字段缺失、尚未验证，或没有录进回放。车型布局仍保持；常规车本来就不显示
  Pro 能量面板。
- **中文标签显示不正常**：在设置里换一个中文字体。
- **诊断日志**：保存在 `Documents\Assetto Corsa\logs\f1_2026_speedometer_hud_diag.log`，多次启动的记录
  会保留在同一文件中。CSP 日志中也能找到标有 `[F1-2026-HUD]` 的相同记录。

## 限制与计划

- 回放最多记录 22 辆车，即车辆索引 0–21；索引 22 及之后的车辆不会录制。
- 普通 FA26 功能少于 Pro，使用独立的数据语义；不承诺其他厂商自定义 2026 mod 或线上远程车同等覆盖。
- 0.9.2 适配器上的 Pro 实时会话（含 AI 车）、混合镜头和实际字体效果仍需游戏内验收；当前完成项及待测项见
  [COMPATIBILITY.md](docs/COMPATIBILITY.md)，离线测试不能代替游戏实测。
